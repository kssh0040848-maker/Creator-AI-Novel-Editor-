## 1. 最快体验：双击 HTML

解压后，用桌面 Chrome / Edge 打开 `打开原型.html`。可以写作、新建故事、调整设定、导入导出，以及体验模拟流式续写、停止、撤销和重做。

默认是**演示模式**：续写使用固定示例，与输入的故事无关；不调用模型，也不能用它评价模型写作质量。真实模型需要启动下面的本地服务。

如果浏览器提示存储不可用，请改用本地服务方式，并先导出已写内容。建议使用普通浏览窗口，避免用无痕窗口存放长期作品。

## 2. Windows 接真实模型

1. 解压整个 ZIP。保留文件夹结构，不要直接在压缩包内双击启动器。
2. 本包已内置官方 Node.js 24.22.2 LTS（Windows x64），无需单独安装 Node.js，也不用管理员权限。请保留 `runtime` 文件夹。
3. 双击 `start-windows.bat`。浏览器会自动打开 `http://127.0.0.1:4317`。
4. 点击左侧“模型连接”或底部的模型名称，填写服务商、接口地址、模型名称和自己的 API Key。
5. 可先点“测试连接”；希望下次免填密钥时勾选“记住此电脑上的密钥”，再“保存并启用”，最后在正文页点击“继续写作”。

不需要 `npm install`，本地服务没有第三方 npm 依赖。启动成功后窗口自动关闭，服务留在后台。结束时点书架底部“退出本地服务”，或双击 `stop-windows.bat`。没有自动打开页面时，手动在浏览器输入上述地址。

启动器优先使用包内运行环境；只有缺少它时才尝试系统已安装的 Node.js 22 及以上版本。随包运行环境来自 [Node.js 官方发布页](https://nodejs.org/en/download/archive/v24.22.2)，下载文件已按官方 SHA-256 清单校验。原始许可保留在 `runtime/node/LICENSE`，来源与校验值在 `runtime/SOURCE.txt`。本包不会向系统安装 Node.js 或修改 PATH。Windows ARM64 设备请使用相应架构的运行环境。

“测试连接”只检查 `/models`，不发起小说生成；有的兼容服务不提供模型列表，需用一次真实续写另行验证。生成会使用模型账户额度。API Key 请在自己的电脑上输入，不要发到聊天里。

### 服务商配置

| 类型 | 配置方法 | 范围 |
| --- | --- | --- |
| DeepSeek 官方 | 保留官方地址，默认模型 `deepseek-flash`；可通过模型列表选择 | 发送关闭思考参数，读取正文流 |
| 自定义兼容服务 | 按服务商文档填写 Base URL、模型名称及 Key，例如地址可能以 `/v1` 结尾 | 支持 OpenAI Chat Completions 风格的文本流 |

只填写基础地址，不要把 `/chat/completions` 或 `/models` 再写进 Base URL。自定义兼容并不代表任意模型都可直接使用；需要不同鉴权、特殊参数、原生 Messages/Responses 协议的服务须单独适配。当前版本只连接标准 HTTPS 公网 API，尚不支持 LM Studio 等本机 HTTP 模型接口。

模型预设依据 [DeepSeek Chat Completions 官方文档](https://api-docs.deepseek.com/api/create-chat-completion/) 核对，核对日期为 2026-11-01。服务商以后变更模型名时，可在设置中修改。

### macOS / Linux

Mac 使用单独的 `创作家-v0.5.5-Mac版.zip`，不包含仅限 Windows 的 `node.exe`。解压 ZIP 后双击 `start-mac.command`，浏览器会打开 `http://127.0.0.1:4317`。脚本会优先使用电脑里已有的 Node.js 22 或更新版本；没有时，首次运行会根据 Apple 芯片或 Intel 芯片，从 Node.js 官方下载 v24.22.2 LTS 压缩包、核对固定 SHA-256 校验值，并保存在本文件夹 `runtime/mac/`，不会安装到系统，不需要管理员权限。首次启动需要联网；以后在同一文件夹里运行不再下载。不需要手动安装 Node.js。

不要在 ZIP 预览窗口里运行脚本。没有自动打开浏览器时可手动输入上述地址；关闭终端窗口即可停止。首次双击若显示“没有权限”，在终端进入解压后的项目目录运行 `chmod +x start-mac.command`，再试双击；也可直接运行 `sh start-mac.command`。脚本的下载或校验失败时会显示原因，并且不会运行未验证文件。

Linux 安装 Node.js 后，在项目目录执行 `sh start-mac-linux.sh`。这两个启动脚本尚未在 macOS / Linux 实机验证。项目不需要 npm 安装第三方依赖。

Mac 和 Windows 的作品默认存于各自浏览器的本地站点数据中，不会自动同步。换电脑时先在旧设备“备份全部故事”，再在新设备导入 JSON。

## 3. 现在能做什么

- 新建、切换、搜索故事，编辑标题和正文。
- 作者输入显示薄荷绿色，模型生成显示浅色；手动改过的部分归为作者文字。
- 续写逐步展示，可中途停止；收到的部分保留。
- 一次撤销整次续写，重做恢复文字与颜色。手工编辑也有撤销记录。
- 生成时自动跟随到底部；向上滚轮或触屏阅读会暂停跟随，可点“回到最新”。
- 故事记忆、作者注、关键词触发世界书，以及实际请求上下文预览。
- 调整输出上限、创意程度、最近正文范围和字号。
- 浏览器本地保存、完整 JSON 备份、TXT 正文导出、旧 APK JSON 备份导入。

## 4. 保存、备份和原 APK 导入

作品保存在**当前浏览器、当前地址的 IndexedDB**。不会自动同步到另一台电脑或手机。建议每次重要写作结束后点“备份全部故事”。不要清理浏览器站点数据，也请只在一个标签页编辑。

| 操作 | 包含内容 |
| --- | --- |
| 导出 | 当前故事的正文 TXT |
| 备份全部故事 | 当前书架中所有故事的正文、文字来源颜色、章节、设定、正文撤销/重做记录和书架顺序 |
| 导入自己的 JSON | 添加为新故事，保留颜色和支持的历史；旧版备份中的已暂存故事作为普通故事导入；不覆盖现有故事 |
| 导入旧 APK JSON | 迁移正文、标题、记忆、作者注与世界书；不迁移账号、旧历史及旧模型参数 |
| 导入 TXT | 作为一个新故事，正文均标记为作者输入 |

旧 APK 的作品需先在旧应用中导出 JSON，再导入网页。安装包本身通常不包含你在手机上写的作品。

`打开原型.html`、`http://127.0.0.1:4317`、`http://localhost:4317`、不同端口、不同浏览器的存档可能相互独立。迁移时先备份，再在新地址导入。建议固定使用 `http://127.0.0.1:4317`。

API Key 默认只在当前页面内存中保留。Windows 本地版勾选“记住此电脑上的密钥”后，使用 Windows DPAPI 的 CurrentUser 方式加密，保存在 `%LOCALAPPDATA%\CreatorStudio\api-credential.dpapi.json`。只记住最近一次启用的服务商和接口；换接口需重新填写。加密文件不包含明文密钥，故事备份也不包含密钥；相同 Windows 账户运行的程序仍可能解密，不能将其视为独立密码保险箱。真实调用时本地代理会将 Key 和请求发送给你指定的服务商，服务商对请求的保存方式由其政策决定。

## 5. 原型边界

- 本地单人使用；正常启动只监听 `127.0.0.1`。手机不能直接打开电脑的这个地址。
- 尚无账户、邀请注册、付费、团队共享、云同步和后台管理。
- 撤销/重做仅针对正文；故事设定与标题尚未纳入撤销。
- 当前是线性撤销/重做；撤销后新写或重新生成会清除原来的重做分支。
- 故事确认后直接删除，无法在应用内恢复；暂不提供章节树、多个候选续写和版本分支。
- 最多 50 个故事；单篇最多 20 万字符；每篇世界书最多 30 条。
- 正文历史最多 30 步并受大小上限约束；长文可能更早移除旧历史。备份文件最大导入 20 MB。
- 最近正文按字符裁剪，不按模型 tokens；记忆与命中的世界书额外加入。输出上限是 tokens，并非保证的中文字数。
- 真实 DeepSeek 调用、其他供应商兼容性、Windows 启动器、小米 K80 与 HyperOS 3.0 都仍需实机验证。本次没有使用你的 Key，也没有产生付费模型调用。

本地版代码可作为迭代基础。公开试用版需要按需求文档补齐部署、权限、额度与相应上线要求。

## 6. 常见问题

**窗口提示找不到 Node.js**：先确认已完整解压本免安装包，且 `runtime/node/node.exe` 存在。不要只复制启动器或在压缩包内直接运行。

**关闭窗口后还需要服务吗**：新版正常启动后不需要保留黑色窗口。关闭网页不会退出后台服务；点“退出本地服务”或运行 `stop-windows.bat`。电脑重启后需再次双击启动器。

**重启后仍要输入 API Key**：确认使用 Windows 本地版而非单文件原型，在“模型连接”勾选记住并保存；使用同一 Windows 账户、浏览器和接口地址。若显示加密失败，可取消勾选临时使用，并提供不含密钥的错误文字。

**端口被占用**：先检查是否已打开本地服务，直接访问原地址。需要换端口时，在项目目录的命令提示符运行 `runtime\node\node.exe server.mjs --open --port 4318`，原地址作品需导出后迁移。

**API 返回 401/402/404/429**：分别优先检查密钥、账户余额、模型和接口路径、服务商限流。失败不会自动反复付费重试。

**“保存失败”或“存储不可用”**：立即导出 TXT/JSON；当前页面仍能展示内容，不要先关页面。修复浏览器存储问题后再导入。

**模型只输出很少或没有正文**：换非思考模型或调整供应商设置。自定义供应商可能把输出额度用于思考；本版不把思考内容插入正文。

## v0.5.5：选择模型服务商

“模型连接”新增 DeepSeek、OpenAI、Claude、Gemini、阿里云百炼千问、xAI Grok、硅基流动、OpenRouter 和自定义选项。选中后会填入对应的 Chat Completions 兼容入口；你仍需填自己的模型名称与 API Key。百炼地址可按地域和业务空间调整，Key 必须与地域匹配。选择并不等于该账号、模型和参数已经完成真实调用验证；可先手填模型名，再点“试写验证”（会产生 API 用量）。
