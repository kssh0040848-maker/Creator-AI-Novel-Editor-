阅读 NovelAI 的公开编辑器与界面设置文档，提取三点通用体验：以正文为工作中心、生成和撤销可以连续操作、菜单与正文字号独立控制。

## 2. 创作家的具体方案

| 用户任务 | 入口与行为 | 设计原因 |
| --- | --- | --- |
| 看清菜单 | 主要菜单 16 px / 18 px；说明约 14 px；主要操作约 44–48 px 高 | 降低辨认和点击成本 |
| 调整阅读 | 顶部「显示」，正文独立 16–24 px | 大菜单不强制改变正文排版 |
| 安静写作 | 顶部「专注」，收起两侧面板并隐藏演示说明条 | 集中注意力，保留退出和设定入口 |
| 连续续写 | 底部固定「撤销 / 重做 / 继续写作」 | 操作位置稳定，中文标签说明含义 |
| 了解生成状态 | 底部操作区上方显示等待、生成、完成或失败 | 不必翻到正文末尾找反馈 |
| 调整创作要求 | 右侧「故事设定 / 生成设置」；较窄窗口使用抽屉 | 常用写作要求和模型参数分组 |
| 理解字段 | 前情与人物、这一段怎么写、世界设定 | 用写作者能直接理解的任务语言 |
| 管理文件 | 左侧书架底部放导入、导出、备份与模型连接 | 全局管理动作集中 |

视觉继续使用黑底、紫色主要操作、薄荷绿作者文字和慧慧。配色、间距、中文文案、布局细节和代码由本项目独立组织。慧慧保持与字标交叠，默认只响应用户鼠标与点击，避免自动弹出抢注意力。

## 3. 本轮边界

正文仍使用线性撤销/重做；撤销后新写或重新生成会清掉重做分支。多候选续写、分支历史、章节树和选中文本改写暂未加入。若后续做「换一个版本」，应先保存候选再切换，避免覆盖用户认可的文字。

桌面可收起右侧设置；窄屏使用带遮罩的侧栏，支持关闭按钮、Escape 和键盘焦点限制。遵循系统减少动态效果偏好。字号与专注偏好保存在本浏览器。
