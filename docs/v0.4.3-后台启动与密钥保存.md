# v0.4.3 后台启动与密钥保存

日期：2026-11-03。目标：Windows 本地版。

## 使用流程

先备份故事并关闭旧服务窗口，完整解压新包。双击 `start-windows.bat` 后网页打开，启动窗口自动关闭。服务在后台保持运行；重复启动会打开现有服务的网页。旧版占用端口时给出提示，不强制结束其他进程。

结束写作时，在书架底部点「退出本地服务」。页面会先保存当前故事，再请求关闭服务；保存失败会留在页面并提示备份。也可用 `stop-windows.bat` 退出。关闭浏览器不自动停止服务；重启电脑后再次双击启动器。不设置开机自启。

调试启动器 `start-windows-debug.bat` 保留前台输出，该窗口关闭会停止它启动的服务。

## API Key

默认不保存。进入「模型连接」，输入密钥，勾选「记住此电脑上的密钥」，点「保存并启用」。下次在同一 Windows 账户下启动，会按浏览器中保存的服务商和接口地址自动恢复密钥。恢复本身不请求模型，不产生模型费用。

只记住最近一次启用的一个接口。切换接口清空输入，避免把原密钥误发给新服务商；不同接口不会自动读取。取消勾选并保存会移除此前记住的密钥，但本页仍可临时使用新输入的密钥。「忘记已保存的密钥」同时移除磁盘记录和当前页密钥。

密钥不会进入 IndexedDB、作品 JSON 备份、日志、命令行参数或发布包。落盘内容是 Windows DPAPI CurrentUser 加密后的数据，位于：

```
%LOCALAPPDATA%\CreatorStudio\api-credential.dpapi.json
```

服务商与接口标识也在加密内容内。PowerShell 的标准输入传递待加密数据，标准输出返回结果；没有明文降级保存。加密失败显示原因，用户可取消勾选临时使用。现有密钥只有在新数据成功加密写入后才替换。

这是当前 Windows 账户范围的保护，同一账户运行的程序可能解密。更换账户或系统后需重新输入密钥。Mac、Linux、单文件原型和开发预览暂不提供此持久化功能。

## 实现入口

| 文件 | 责任 |
| --- | --- |
| `launcher.mjs` | 后台启动、就绪检查、复用、退出 |
| `credential-vault.mjs` | Windows 加密、读取、原子替换与遗忘 |
| `server.mjs` | 会话、来源与令牌验证、密钥接口、退出接口 |
| `web/local-services-ui.mjs` | 勾选保存、恢复、遗忘、退出提示 |
| `app-info.mjs` | 应用与版本标识 |
| `tests/local-service.test.mjs` | 后台启停及密钥生命周期检查 |

`.bat` 文件统一为 ASCII 文本、CRLF 换行，中文状态由 Node 输出，避免 CMD 将乱码片段当成命令。

## 验证记录

- `npm test`：37 项通过。包括原有写作、文风、迁移和模型调用检查。
- 在当前 Linux 环境运行后台启动器：父进程退出后服务仍在、重复启动复用、鉴权退出成功。
- 密钥存储生命周期使用测试加密适配器验证：默认不落盘、显式保存、重建服务后读取、接口不匹配不返回、遗忘移除、加密失败保留旧文件。
- PowerShell 调用用进程替身检查：CurrentUser 范围、密钥只走标准输入、命令参数不含密钥。
- API 路由验证来源与会话令牌；不允许网页静态访问密钥或服务器源码。
- Windows DPAPI 和双击批处理未在原生 Windows 实机运行；不能把上述替身测试视为 Windows 实测。
- 没有使用真实 API Key，也没有发起付费模型调用。

## 本机验收

第一次打开后输入 Key、勾选记住并保存。退出本地服务，关闭网页，重新双击启动。确认无需重填 Key，再手动进行一次模型验证。之后可以测试「忘记已保存的密钥」，重新打开应提示填写。任何截图请遮住密钥。
