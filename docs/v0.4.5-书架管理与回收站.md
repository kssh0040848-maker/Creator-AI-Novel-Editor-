# v0.4.5 书架管理与回收站

日期：2026-11-04。目标：在左侧书架直接管理故事。

- 每个故事行的「管理」始终可见，鼠标和触屏都可操作。弹窗可更改故事名称，立即同步到正文标题和书架。正文上方仍可直接改名。
- 「调整顺序」进入移动模式，↑ 和 ↓ 分别将对应故事移动一位；搜索临时关闭，避免在筛选结果里误判位置。再次点击「完成排序」。原书架数组顺序保存于原浏览器存档，重新打开保留；编辑正文不会自动重排。
- 「删除故事…」打开二次确认，展示要移走的名称。确认后进入回收站。回收站保存完整故事对象，包括所有章节、来源颜色、记忆、作者注、世界设定与正文历史。这里不会自动清空；删除最后一篇时创建一个空白故事，保证工作台仍可使用。
- 点击「回收站」里的「恢复」，按原位置插回书架并选中。书架上限 50 篇；满额时先移走一篇再恢复。标题、内容和历史不因移动改变。
- 每次改名、排序、删除和恢复立即尝试浏览器本地保存；保存失败时恢复操作前书架状态并提示备份。全部数据仍只在当前浏览器的本地站点存档里。
- 完整 JSON 备份新增 `trash` 字段，格式 `storydesk-local-v3`，保留书架顺序。v0.4.5 导入兼容旧备份并可带入新备份中的回收站故事；导入项目会生成新 ID，避免与现有故事冲突。单篇 TXT 导出不包含回收站。

验证：`npm test` 50 项通过；浏览器在本地预览中走过改名、调序、刷新、删除、刷新和恢复，正文内容保持不变。未使用用户真实故事或 API Key。Windows 安装包的原生双击启动仍待 Windows 电脑验证。

源码入口：`web/shelf-model.mjs`、`web/shelf-ui.mjs`、`web/app.mjs`；`tests/shelf.test.mjs` 为保存与备份边界检查。
