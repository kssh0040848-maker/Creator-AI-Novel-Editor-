# v0.4.6 Windows 启动修复

双击 `start-windows.bat`，先启动后台服务并等待就绪，再由 Windows 批处理直接打开 `http://127.0.0.1:4317/`。自动打开失败时，脚本会显示该地址并暂停，用户可复制到浏览器。不要直接在 ZIP 压缩包的预览窗口内运行，需完整解压。

旧版 v0.4.3–v0.4.5 后台服务占用该地址时，新版只对身份为 `creator-studio-local` 且提供会话令牌和退出接口的服务发送退出请求。旧版正在生成时退出会被拒绝，保留旧服务；其他程序占用端口也不会被关闭。再次探测使用短连接，避免复用旧版 HTTP 连接取得过期会话。退出成功后才启动新版服务。

作品和书架顺序保存在原浏览器的本地存储，继续使用同一浏览器和相同地址即可读取。升级前先点「备份全部故事」。记住的密钥仍在同一 Windows 账户的加密文件中，本次未迁移或改写。

本环境已做启动器交接的真实本地 HTTP 进程测试、Windows 脚本静态检查和其他已有自动检查；没有原生 Windows 机器验证浏览器关联、Windows 安全软件与双击体验。若仍打不开，双击 `start-windows-debug.bat` 并保留窗口，将**错误文字**发来；不要发送 API Key。
