# v0.4.7 故事直接删除

左侧每篇故事点「管理」→「删除故事…」，核对弹窗中的标题后点「确认删除」。该故事的正文、章节、设定和编辑历史会从当前浏览器书架直接删除，不提供应用内恢复。保存失败时会取消操作并恢复原故事。删除最后一篇时留下一个空白故事。重要内容请先点「备份全部故事」。

从 v0.4.5 或 v0.4.6 升级时，旧版回收站中的故事会在第一次打开后自动放回书架，确保它们不因入口移除而被隐藏。导入旧版完整 JSON 备份时，其中暂存的故事也会作为普通故事导入。新生成的备份只包含书架中可见的故事和顺序，不再生成回收站字段。

本版本的删除逻辑、升级转换、备份导入及保存失败回滚经过自动检查。Windows 原生双击与真实 API 调用仍需在用户电脑上确认。
