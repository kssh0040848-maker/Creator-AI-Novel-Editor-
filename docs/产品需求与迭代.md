## 一、我们要做的产品

为喜欢“自己写一点、AI 接着写一点”的小说作者提供一个创作工作台。核心流程是：打开故事 → 写正文 → 配置前情和要求 → 续写 → 保留、修改或撤销 → 继续写。

保留用户喜爱的小说创作逻辑，逐步支持更多模型。首先让发起人本人用得顺手，再考虑少量受邀用户和公开发行。

本轮最重要的两个已知问题：

1. 新文字出现时，内容面板应跟随到底部。
2. 回退应真的移除本次生成文字，前进应恢复文字与颜色。

## 本轮已确认与完成

用户选择 B 形象，并命名为「慧慧」；要求她与「创作家」文字重叠，可捧着或趴在字上。采用趴在字标上沿的布局，手指、袖口与发丝处于文字前方。鼠标移动时轻微探头，点击会显示灵感短句并跳动，设置中可以隐藏。当前为透明插画与网页动画组合，无语音、无聊天模型调用。

按用户反馈，将默认故事更换为原创开头《星期八的早餐店》，新安装和旧版升级均默认打开该故事；配色已改为黑底、紫色主色与薄荷绿点缀。

## 四、当前设计与行为规则

### 界面草案

桌面左侧为故事书架，中间为正文，右侧为创作设定；正文底部放续写、撤销、重做。窄屏将两侧面板收进抽屉。默认黑色阅读区域、浅色 AI 文字和薄荷绿色作者文字，紫色主操作按钮。

本轮确认了黑底、潮流配色，以及慧慧与「创作家」字标交叠的品牌组合；布局、按钮位置与面板方式仍可按体验继续调整。

### 回退/前进的定义

- 按一次撤销：回到本次续写之前的正文，或撤销最近的一组手动编辑。
- 按一次重做：恢复刚撤销的正文及文字来源。
- 已经撤销后再次修改或生成：开始新的线性历史，原重做内容不再保留。
- 中途停止：把收到的部分当作一次续写，可整次撤销。
- 记忆、作者注、世界书和标题当前不在正文历史中。

如果你想要的是“切换多个候选版本并随时回到任意分支”，需要将这一规则升级为分支版本系统，列为下一阶段候选需求。

### 模型与内容

演示模式只验证操作。真实写作质量、前情连贯性、风格和速度，需要用真实模型及你的故事样本评估。当前按最近正文字符数裁剪上下文，重要旧剧情由故事记忆补足。

## 六、小范围试用草案

此处是产品规则提案，邀请系统还没有实现。

- 先邀请 5–10 位真正会写小说的人，试用约 14 天。
- 一人一码、一次使用，邀请码可关闭；不开放自行传播的注册入口。
- 首轮优先考虑用户自带 API Key；若由你承担调用费，需要后台执行每人及全站额度限制。
- 先观察能否顺利完成一次续写、是否反复使用、撤销是否可靠、最常见中断原因。
- 费用用实测 tokens 和调用量估算，再决定付费模式；本轮演示体验没有模型调用成本。
- 对外试用前，需补账号隔离、服务端额度控制、备份恢复和必要的发布核对。邀请码本身不能替代这些工作。

## 七、下一次交付的完成标准

收到你最想改的三处后，形成 v0.2.1 小范围需求表。优先修复 P0 问题，然后完成确认的界面调整。至少一个真实模型在你的电脑跑通，导入一份真实旧故事，并做一次“生成 → 停止 → 撤销 → 重做 → 备份”的完整验收，再安排首批试用。
