# 创作家变更记录

日期：2026-11-04。

## v0.4.7 · 故事确认后直接删除

- 移除回收站入口、恢复弹窗和新增回收站数据；删除确认后直接从当前书架移除整篇故事。
- 升级时把旧版回收站中的已有故事放回书架，旧版备份导入也将其作为普通故事。
- 保留标题修改、故事排序、删除失败回滚和其余写作功能。

## v0.4.6 · Windows 启动修复

- 启动脚本等待服务就绪后直接打开浏览器；失败时显示本地访问地址与错误。
- 已知旧版后台服务通过自身退出接口自动交接；其他程序占用端口时不予停止。
- 本地探测关闭旧 HTTP 连接，避免读到过期旧会话而误判新版未启动。
- 保留 v0.4.5 的故事管理和全部已有功能；不改浏览器存档与密钥保存位置。

## v0.4.5 · 书架管理

- 每篇故事右侧常显“管理”，提供改名与确认后移到回收站。
- “调整顺序”用上移/下移手动排序，顺序持久化；回收站支持完整恢复。
- JSON 备份含回收站与顺序，导入 v3 格式保留章节、颜色和历史。
- 保存失败时回滚改名、排序、删除与恢复；浏览器核查刷新后持久化。
- 50 项自动化检查通过；Windows 原生行为和真实模型未在本环境测试。

## v0.4.4 · 续写衔接

- 续写使用最新正文，强调不重写作者刚改的末句。
- 新增流式开头重合检查：只移除与原文末尾明确一致的输出前缀。
- 保留流式中断时已收到的新文字，支持撤销/重做，不修改旧正文。
- 47 项检查通过，包括模拟模型重复输出的 HTTP 联调。
- Windows 包更新；未使用真实 Key，未作付费调用。

## v0.4.3 · Windows 使用便利性

- 后台启动，启动窗口自动退出；新增页面退出与独立停止脚本。
- 可选记住 API Key：Windows 当前账户加密保存，按接口恢复，可手动遗忘。
- 批处理改为 ASCII/CRLF，修复中文片段被误当作命令的问题。
- 保留 v0.4.2 的全部写作与新手功能；本次仅更新 Windows 包。
- 37 项自动化检查通过，未使用真实 Key；Windows 原生行为仍需实机确认。
- 完整范围见《v0.4.3-后台启动与密钥保存》。
