# 创作家 v0.5.5 发布留档

本包包含自 v0.5.3 导入基线延续的完整 Git bundle、v0.5.5 提交标识、五个最终交付文件的 SHA-256 校验清单和最近提交摘要。

先取得同版本的 Windows、Mac 或 GitHub 源码 ZIP。校验压缩包时，对下载的文件计算 SHA-256 并与 SHA256SUMS.txt 比较；这些哈希不是第三方可信时间戳或数字签名。可运行 `git clone creator-studio.bundle project` 查看源码历史和 v0.5.5 标签。此 bundle 是历史记录，不含 Windows 运行环境。

本次未用真实 API Key 调用外部模型。服务商菜单只提供经文档核对的兼容入口；实际可用性由账户权限、地域、模型名及服务商参数决定，建议用应用内「试写验证」逐个确认。
