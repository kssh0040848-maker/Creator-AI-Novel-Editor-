1. 解压整个 ZIP，打开解压后的 creator-local 文件夹。
2. 双击 start-mac.command。首次运行需要联网，脚本会自动识别 Apple 芯片或 Intel 芯片，从 Node.js 官方下载对应运行环境并校验；以后同一文件夹内启动不再下载。不需要手动安装 Node.js，不需要管理员权限。
3. 浏览器自动打开 http://127.0.0.1:4317。未自动打开时，把这个地址输入浏览器。
4. 左侧书架里有「模型连接」，请只在自己电脑上填写 API Key。演示模式不调用模型；真实续写按服务商规则产生费用。
5. 故事保存在当前电脑、当前浏览器。重要作品请定期点「备份全部故事」，跨设备用 JSON 导入。

首次双击若提示没有权限：打开终端，进入解压后的 creator-local 文件夹，执行 sh start-mac.command。下载失败时保持联网，重新双击即可。关闭启动窗口会停止本地服务。

源码、依赖配置、详细说明见 README.md；Mac 实机启动尚待验证。

本次更新：黑蓝写作台与无底图字标；右栏世界设定随当前故事切换。升级前请备份全部故事，关闭旧服务窗口；仍用原浏览器及 http://127.0.0.1:4317/。Mac 版不会记住 API Key。Windows 和 Mac 的前端与本地服务源码相同。

产品介绍：打开网页后点击右上角「产品介绍」，或双击此文件夹的「创作家-产品介绍.html」。
